# エージェントの決まり（Antigravity など、会話のたびにこのファイルを読む AI 向け）

秀エクセルマネージャー（MCP サーバー `excel-manager`）で Excel を触るときの決まりです。
Claude Code には同じ手の型がスキル（`.claude/skills/excel-vba-manager`）で届きます。

1. **道具を直撃する**
   - Excel の話が出たら、最初の手で `excel-manager` の道具を撃つ。表の修正なら `vba("seiri 頼みの文")`、それ以外は `vba("materials")`。
     スキルの説明ファイルや道具の定義ファイルを先に読みに行かない（使い方は、形を外せば道具が手本つきで返す）。
   - `vba` は MCP サーバー `excel-manager` の道具。シェル（run_command）で `vba ...` や `python ...` を撃たない（シェルには無いので必ず失敗する）。

2. **表の修正は先撃ち（`seiri 頼みの文` を 1 回）**
   - 頼みの文をそのまま渡すと、表を整えるマクロ・頼みに当たる棚のマクロ・`tidy` の仕上げまで、道具が 1 回の呼び出しで撃つ。
     頼みの語が無い「表の修正」だけなら、シートに書いてある頼みの文を渡す。
   - 返事の「残り」（エラーの式など、棚で直らない所）があるときだけ、表と式を見て `write-cells` と `tidy` を同じ返事に並べて 1 回で撃つ。
   - ブックの中の既存マクロで片付けない。直す手を探してソースやマクロ一覧を読みに行かない。
   - 画面の写し（`screenshot`）は頼まれたときだけ。道具の返事に出ていないことを報告しない。終わったら要点だけ 1〜3 行で報告する（何をどこに直したかを番地で。経過・秒数・長い説明は書かない）。
