# 秀エクセルマネージャー（開発中のものを、そのまま公開しています）

Excel の VBA マクロ・シート・テーブル・ピボット・グラフ・パワークエリを、**Python 経由で AI が直接さわれるようにする道具**です。
Claude Code や Antigravity（Gemini）に MCP サーバー `excel-manager` として登録すると、開いている Excel ブックに対して、
会話でマクロを直す・作る・表を整える、ができます。

> ⚠️ **研究中の道具です。** 版は 0.x、仕様は予告なく変わります。動作の保証はありません。
> 自分のブックを相手に、家で使っているものを、手元の姿のまま出しています。大事なブックには、必ず控えを取ってから使ってください。

前身の「秀VBAマネージャー」は、2026 年 9 月 5 日の姿のまま残してあります（以後は更新しません）。
https://github.com/shu1551/shu-vba-manager

## 何が出来るようになったか

五月に「会話するだけでマクロが直る」から始めた道具です。四か月のあいだに、AI が実物の Excel の中で
**VBA を入れる・コンパイルする・撃つ・結果を読み戻す・だめなら戻す**、の足場が出来ました。

その足場の上に、表を直すマクロの**棚**（アドイン「秀コンボ」の中の 169 本。2026-10-28 に数えた数で、今の本数は `py vba_manager.py shelf` の 1 行目に出ます）が載っています。

1. 依頼が来たら、頼みの文に当たる棚のマクロを、道具が AI より先に撃つ（`seiri 頼みの文` の 1 回・数秒）
2. マクロで片付かなかった**残り**だけを AI に返し、AI はそこだけ直す

**決まった作業はマクロ、AI は想定外の所だけ**、という分け方です。AI に考えさせる回数が減るので、速くて、毎回同じ結果になります。

2026 年 9 月には、AI がやった仕事を AI 自身がマクロに書き、正解つきのお題で試して棚に登録する「鍛える回路」も載せていましたが、
10 月 8 日に外しました。棚のマクロは、人が仕事で使って、外れたところを AI と会話しながら直して育てています。

### 入口は三つです

| 入口 | 向いている人 | 開き方 |
|---|---|---|
| Excelコンボ | 表の前で、言葉で頼みたい人。頼みの文に当たる棚を先に撃ち、外れたら AI に回します | Ctrl + Shift + A、目次シートのボタン、またはマクロ一覧から |
| 統合マクロフォーム | マクロを探して撃つ・直す・並べ替える・管理したい人。業務レシピもここから | Ctrl + Shift + O ／ I ／ P |
| エクセルマネージャー（MCP） | Claude Code や Antigravity に、表やマクロを直させたい人 | 下の「MCP サーバーとして登録する」 |

### AI の窓（Excelコンボ・統合マクロフォームの［AI修正］・AI数式）

- Excelコンボと統合マクロフォームは、AI の欄で **claude** か **gemini(直)** を選べます
  - **claude**: Claude Code をインストールしてログインしておけば、API キーは要りません（窓が裏で `claude` を呼びます）
  - **gemini(直)**: Gemini の API キーが要ります。Excelコンボの API キーの欄か、統合マクロフォームの設定タブに入れます（同じ置き場です）。空なら環境変数 `GEMINI_API_KEY` を読みます
- 選んだセルの式を作る／解説する AI数式は、Claude Code で動きます
- AI の窓を使わなければ、AI が無くてもアドインのほかの道具は動きます

### 道具とアドインの関係

道具（Python）が AI と Excel をつなぐ側、アドイン（VBA）が表を直す側です。依頼が来ると、道具の入口は、開いているブックやアドインの中の
「表の整理」モジュールを読み、マクロの頭に書いてある「依頼の語」に当たるものを、AI より先に撃ちます。
アドインだけでも、マクロは一覧から人の手で撃てます。

## 動く条件

- Windows 版の Excel（デスクトップ版）
- Python 3.10 以降（`py` コマンド）と `pip install -r requirements.txt`
- Excel のトラストセンターで「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にする
- **手を動かす AI**。この道具は AI の手であって、AI そのものではありません。Claude Code や Antigravity のように、MCP で道具につなげる AI を
  別に用意してください。**API キーは要りません。** つないだ AI 自身が頭になります。依頼文を渡して最後まで回す命令（agent）も、
  既定では道具が裏で Claude Code（`claude -p`）を呼ぶので、鍵は要りません。Gemini / Claude の API を直接使う道も残してありますが、使いたい方だけの選択肢です。
- AI がいなくても、道具の本体（マクロの取得・置換・シートの読み書き）は、人がコマンドを一行ずつ撃てば動きます（`py vba_manager.py list` など）。
  アドイン（秀コンボ.xlsm）は、Excel だけで動きます（AI の窓だけは Claude Code が要ります）

よその方のパソコンでは、まだ動かしていません。確かめたのは、作者の一台（Python 3.14）で動かしてきたことと、このリポジトリの中身を別の場所に展開して、
そこから MCP サーバーが立ち上がることまでです。

## 使い始める手順（アドインの登録を忘れずに）

道具（Python）だけ入れても、**表を直すマクロ（棚）は動きません。** 棚は秀コンボの中にあるので、秀コンボを Excel にアドインとして登録してください。

1. **ZIP のブロックを外す。** GitHub の「Code → Download ZIP」で落とした ZIP は、展開する前に右クリック →「プロパティ」→
   下の「許可する（ブロックの解除）」に印を付けて OK。外さずに展開すると、Excel が秀コンボのマクロを止めます
   （「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました」）。`git clone` した方は要りません
2. **Python の部品を入れる。** このフォルダで `py -m pip install -r requirements.txt`
3. **Excel の設定を 1 つ。** 「ファイル → オプション → トラスト センター → トラスト センターの設定 → マクロの設定」で
   「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」に印
4. **秀コンボをアドインとして登録する。** `秀コンボ.xlsm` を開き、「コンテンツの有効化」を押してから、目次シートの
   **「アドインの更新登録」** ボタンを押します。`秀コンボ.xlsm` の写しが `%APPDATA%\Microsoft\AddIns\秀コンボ.xlam` として書き出され、
   アドインに登録されます。次からは Excel を開くたびに自動で読み込まれるので、`秀コンボ.xlsm` は閉じてかまいません
   （秀コンボのマクロを直したときは、`秀コンボ.xlsm` を開いてもう一度このボタンを押すと、アドインが入れ替わります）
5. **AI につなぐ。** 下の「MCP サーバーとして登録する」と「スキル（手順書）を入れる」
6. **使うときは、先に Excel で相手のブックを開いておく。** 道具は、今前に出ている（アクティブな）ブックを相手にします。
   Excel が開いていないと、道具は何もできません
7. **つながったかを確かめる。**
   - Claude Code なら、`claude mcp list` で `excel-manager` の行に「Connected」と出れば、道具は立ち上がっています
   - 表の入ったブックを開いて、AI に「**開いているブックとシートを教えて**」と頼みます。ブックの名前とシートの一覧が返ってくれば、Excel までつながっています
     （手元に試してよい表が無ければ、次の「最初の 1 回」の手順 1・2 で試しの表を作って開いてください）
   - 棚（秀コンボ）まで届いているかは、続けて次の「最初の 1 回（試しの表で）」で確かめます

### 最初の 1 回（試しの表で）

自分のブックの前に、汚れを仕込んだ試しの表で、棚を 1 回撃ってみます。試しの表は台本が毎回作り直すので、壊しても困りません。

1. **試しの表を作る。** `作業ファイル\project\fixtures\はじめての表\` で次を実行します（Excel は使いません。手順 2 で入れた `openpyxl` で作ります）

   ```powershell
   py make_sample.py
   ```

   同じフォルダに `はじめての表.xlsx` ができ、仕込んだ汚れが番地で出ます。

   ```text
   作りました: はじめての表.xlsx（シート「売上」・見出し 1 行目・明細 2〜10 行目・合計 11 行目）
   仕込んだ汚れ:
     B3    空白の揺れ（後ろに半角の空白）  … 「鈴木 花子 」→「鈴木 花子」
     B5    空白の揺れ（姓と名の間が全角の空白）  … 「佐藤　一郎」→「佐藤 一郎」
     B6    空白の揺れ（姓と名の間に空白が無い）  … 「田中次郎」→「田中 次郎」
     D4    文字の数字  … 文字の「20」→ 数の 20
     E6    文字の数字  … 文字の「1500」→ 数の 1,500
     行8    空行  … 行ごと消して詰める
     行10   重複行（行2 と全部の列が同じ）  … 行ごと消す
     行11  合計の行（D11・E11 は SUM の式）… 残す
   合計の行の値: 開いた直後 数量 49・金額 10,520（SUM は文字の数字を数えない） → 直った後 数量 64・金額 9,520（文字の数字を数え、重複行を除く）
   ```

2. **Excel で開く。** `はじめての表.xlsx` を開いて、前に出しておきます（秀コンボはアドインとして読み込まれた状態で）
3. **AI に頼む。** Claude Code（または Antigravity）に「**この表を整えて**」と頼みます。AI は道具の `seiri` を 1 回撃ちます
4. **何が直るかを見る。** 番地は、台本が作ったときの番地です

   | 番地 | 開いた直後 | 直った後 | 撃つマクロ（棚） |
   |---|---|---|---|
   | B3 | 「鈴木 花子 」（後ろに空白） | 「鈴木 花子」 | 表の書き方と罫線と列幅をそろえる |
   | B5 | 「佐藤　一郎」（全角の空白） | 「佐藤 一郎」 | 表の書き方と罫線と列幅をそろえる |
   | D4・E6 | 文字の「20」「1500」 | 数の 20・1,500 | 表の書き方と罫線と列幅をそろえる |
   | 行8 | 空行 | 行ごと消えて、下の行が上がる | 表の中の空行を削除して詰める |
   | 行10 | 行2 と全部の列が同じ行 | 行ごと消える | 全列が同じ重複行を削除する |
   | B6 | 「田中次郎」（空白が無い） | 「田中 次郎」（列の中で多い方の書き方） | 空白の有無を多い方にそろえる |
   | 行11（合計） | 数量 49・金額 10,520 | 行9 に上がり、数量 64・金額 9,520 | 式はそのまま（文字の数字が数になり、重複行が抜けた分） |

   - 罫線・列幅・数の表示形式も変わります（道具の返事では「書式の変化」の行に件数が出ます）
   - 行を消すと下の行の番地が上がります。そのため重複行は、空行を詰めた後の番地（行9）で返事に出ることがあり、
     「マクロが直したセル」には、上がった行のセルも並びます
   - 「マクロ: モジュール「表の整理」の 表の書き方と罫線と列幅をそろえる が開いているブック・アドインに無いので撃っていません」という返事なら、
     秀コンボが読み込まれていません（上の手順 4 をやり直してください）
5. **元に戻す。** AI に「**元に戻して**」と頼むと、撃つ前の表に戻ります（道具は撃つ前に控えを取っています。AI は `agent` の `undo=True` を撃ちます）。
   `seiri` はブックを保存しません。もう一度試すときは、Excel で `はじめての表.xlsx` を保存せずに閉じ、手順 1 からやり直してもかまいません

### アドインを入れた後の入口（ショートカットキー）

アドインを登録すると、次のキーが使えるようになります。まずは **Ctrl + Shift + O**（アドインのマクロ一覧）から、入っているマクロを一覧で選んで撃てます。
マクロ一覧の 3 つのキーは、どれも統合マクロフォームで開きます（タブで切り替えられます）。
Excelコンボ（AI の窓）は **Ctrl + Shift + A** で開きます（この一覧か、`秀コンボ.xlsm` の目次シートのボタンからも開けます）。

| キー | 開くもの |
|---|---|
| Ctrl + Shift + O | 統合マクロフォーム：アドインのマクロ一覧（秀コンボに入っているマクロを選んで撃つ。表を直すマクロもここ） |
| Ctrl + Shift + I | 統合マクロフォーム：アクティブなブックのマクロ一覧 |
| Ctrl + Shift + P | 統合マクロフォーム：個人用マクロブック（PERSONAL.XLSB）のマクロ一覧 |
| Ctrl + Shift + A | Excelコンボ（AI の窓。頼みの文に当たる棚を先に撃ち、外れたら AI に回す） |
| Ctrl + Shift + U | 直前に撃ったマクロをもう一度 |
| Ctrl + Shift + S | ショートカットキーの管理（キーの付け替え） |
| Ctrl + Shift + W | ワークシートの一覧 |
| Ctrl + Shift + K | カレンダー |
| Ctrl + Shift + J | 選んだ図形の倍率・回転 |
| Ctrl + Shift + T ／ Y | 絞り込み検索の窓／オートフィルターの絞り込みを解除 |
| Ctrl + Shift + C | アクティブセルの見えている文字をコピー |
| Ctrl + Shift + N | アクティブなブックを保存して閉じる |

キーはご自分の使い方とぶつかることがあります。Ctrl + Shift + S のショートカットキーの管理で付け替えられます。

### 新しい版に入れ替える・アドインを外す

- **入れ替える**: 新しい版を落として（ZIP ならブロックを外して）、新しい `秀コンボ.xlsm` を開き、目次シートの「アドインの更新登録」を押します。
  前のアドインに入れてあった設定（祝日・定型の指示・一覧の分類など）は、新しいアドインへ引き継がれます
- **外す**: 「ファイル → オプション → アドイン → 管理: Excel アドイン → 設定」で「秀コンボ」の印を外します。
  ファイルごと消すなら `%APPDATA%\Microsoft\AddIns\秀コンボ.xlam` を削除します

アドインが無いときに動かないのは、棚を使う手だけです。道具は、同じ Excel で開いているブックとアドインの全部から
「表の整理」のモジュールを探すので、アドインに登録しなくても、`秀コンボ.xlsm` を開いておけば棚は使えます
（そのときも、直したいブックのほうを前に出しておいてください）。

| 手 | 秀コンボ（.xlam も .xlsm も）が読み込まれていないと |
|---|---|
| `seiri`（表を整えて残りを報告） | 表を整えるマクロを撃たずに、残りの報告だけを返します |
| `shelf`・`shelf-run`（棚を選ぶ・撃つ） | 棚が見つからず、撃てません |
| 依頼の先撃ち（agent） | 登録済みのマクロが無いので、毎回 AI が一から作業します |
| マクロの取得・置換・シートの読み書き・`tidy` など | アドインが無くても動きます |

## MCP サーバーとして登録する

Claude Code:

```powershell
claude mcp add excel-manager --scope user -- py "<このフォルダの絶対パス>\作業ファイル\project\python_scripts\vba_mcp_server.py"
```

Antigravity（`%USERPROFILE%\.gemini\antigravity-ide\mcp_config.json`）:

```json
{
  "mcpServers": {
    "excel-manager": {
      "command": "<python.exe の絶対パス>",
      "args": ["<このフォルダの絶対パス>/作業ファイル/project/python_scripts/vba_mcp_server.py"]
    }
  }
}
```

対象は常に「今アクティブに開いている Excel ブック」です。特定のブックやパスには依存しません。

## スキル（手順書）を入れる

`.claude/skills/` の手順書（excel-vba-manager・excel-userform-builder）は、道具の正しい使い方（表を直すときは棚を先に見る・
書いたら仕上げまでやる、など）を AI に教えるものです。Claude Code は、**起動したフォルダの** `.claude/skills/` しか読みません。

- このフォルダで Claude Code を起動して使うなら、そのままで読まれます（`CLAUDE.md` も同じ）
- ほかのフォルダから使うなら、`.claude\skills\` の中の 2 つのフォルダを `%USERPROFILE%\.claude\skills\` へ写してください。PowerShell なら次の 2 行です

  ```powershell
  New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
  Copy-Item -Recurse -Force "<このフォルダの絶対パス>\.claude\skills\*" "$env:USERPROFILE\.claude\skills\"
  ```
- **Antigravity（Gemini）で使うとき**は、**このフォルダをワークスペースとして開いてください。** Antigravity は、ワークスペースの
  `.agents\AGENTS.md` を会話のたびに読みます。そこに、表の修正は先撃ち（`seiri` を 1 回）で済ませる・`vba` をシェルで撃たない、
  という決まりを入れてあります。
  - ほかのフォルダをワークスペースにするなら、`.agents\AGENTS.md` をそのフォルダの `.agents\` へ写してください
  - `seiri` は、表を整えるマクロと、見つけた汚れ（重複行・空行・先頭のゼロ・空白の揺れ・文字の日付・式のずれ）に当たる棚のマクロ、`tidy` の仕上げまで、
    道具が 1 回の呼び出しで撃ちます。使う人の頼みの文を渡すと、頼みに当たる棚も同じ呼び出しで撃ちます。
    棚を 1 手ずつ撃つと、手の間ごとに AI が考えるので遅くなります（2026-09-24 の試し）

手順書が無くても道具は動きますが、AI が道具の使い方を一から探るので、手数が増えて遅くなります。

## 名前について

ファイル名（`vba_manager.py`）や道具の名前（`vba("…")`）には、前身の名前が残っています。中身を先に出すことを優先しました。
